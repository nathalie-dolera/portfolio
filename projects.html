ALERTO: Development of a Location-Based Alert System for Enhancing Commuter Safety and Security

IoT and Capstone Project

IoT Hardware Module
Mobile App
Team Members: Antonio, Princess Fiona • Dolera, Nathalie • Jomoc, Justine • Medilo, Mira Mae
My Role: Programmer for System and Hardware
Web System Mobile APK

Description

ALERTO combines an anti-theft bag device and a mobile application into one complete safety ecosystem. The system is designed to help commuters stay alert near their destinations, protect their personal belongings from theft, monitor travel safety, and provide continuous emergency connectivity.

Technologies & Components Used

Hardware & IoT Components: ESP32-S3 Microcontroller, Neo-M8N GPS Module, Air780E 4G LTE/GSM Module, MPU6050 Motion Sensor, Magnetic Reed Switch, LDR (Light) Sensor, Active Buzzer, Vibration Motor, and Custom 3D-Printed Enclosure.

Software, APIs & Cloud: C / C++ (Firmware), React Native & Expo, MapLibre Native & OpenFreeMap, Google Gemini AI (OCR), TomTom Traffic API, Next.js & Vercel (Admin), MongoDB Atlas & Prisma, iProg SMS Gateway, and Bluetooth Low Energy (BLE).

Ligtas Sundo: QR Code and RFID with SMS Notifications and Cloud Storage for Noveca Day Care Student Dismissal

Third Year Project

Hardware
Mobile App
Team Members: Antonio, Princess Fiona • Dolera, Nathalie • Jomoc, Justine • Medilo, Mira Mae
My Role: Backend Developer

Note: Built as an on-site local prototype and not publicly deployed. The codebase is kept in private repositories, but access and code walkthroughs are available upon request. (via Contact).

Description

Ligtas Sundo is a technology-driven student dismissal management system designed for Noveca Day Care Center. It integrates RFID for student arrival cross-checking, QR code scanning for authorized fetcher verification, SMS notifications for real-time parent updates, and cloud storage for secure and accessible dismissal records — replacing unsafe and error-prone manual pickup procedures.

Technologies & Components Used

Hardware & IoT Components: RFID Reader (USB 13.56 MHz), RFID Cards (Student IDs), ID Card Printer, and Laptop (teacher workstation).

Software, APIs & Cloud: Node.js & Express.js (Backend), Flutter Web (Frontend), MongoDB Atlas & GridFS (Cloud Database), iProg SMS Gateway (SMS Notifications), JWT Authentication, and BCrypt (Password Hashing).
